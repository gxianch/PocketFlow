# PocketFlow 入门示例

您的第一个 PocketFlow 应用程序！此简单示例演示如何从头开始创建基本的 PocketFlow 应用。

## 项目结构

```
.
├── docs/          # 文档文件
├── utils/         # 工具函数
├── flow.py        # PocketFlow 实现
├── main.py        # 应用程序入口点
└── README.md      # 项目文档
```

## 环境配置

1. 创建虚拟环境：
```bash
python -m venv venv
source venv/bin/activate  # Windows 系统：venv\Scripts\activate
```

2. 安装依赖项：
```bash
pip install -r requirements.txt
```

3. 运行示例：
```bash
python main.py
```
