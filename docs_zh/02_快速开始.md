## 第一个示例：Hello World

让我们创建一个最简单的节点：

```python
from pocketflow import Node, Flow

# 1. 定义节点
class HelloNode(Node):
    def prep(self, shared):
        """准备阶段：获取输入"""
        return shared.get("name", "World")

    def exec(self, prep_res):
        """执行阶段：处理逻辑"""
        return f"Hello, {prep_res}!"

    def post(self, shared, prep_res, exec_res):
        """后处理阶段：存储结果"""
        shared["greeting"] = exec_res
        print(exec_res)

# 2. 创建并运行
node = HelloNode()
shared = {"name": "PocketFlow"}
node.run(shared)

# 输出: Hello, PocketFlow!
print(shared["greeting"])  # Hello, PocketFlow!
```

## 第二个示例：简单流程

使用 Flow 连接多个节点：

```python
from pocketflow import Node, Flow

# 节点1：获取用户输入
class InputNode(Node):
    def prep(self, shared):
        return shared["question"]

    def exec(self, question):
        return question.upper()

    def post(self, shared, prep_res, exec_res):
        shared["processed"] = exec_res
        return "next"  # 返回 action，决定下一步

# 节点2：生成回答
class AnswerNode(Node):
    def prep(self, shared):
        return shared["processed"]

    def exec(self, processed):
        return f"You asked: {processed}"

    def post(self, shared, prep_res, exec_res):
        shared["answer"] = exec_res

# 创建节点实例
input_node = InputNode()
answer_node = AnswerNode()

# 连接节点（使用 >> 操作符）
input_node >> answer_node

# 创建流程
flow = Flow(start=input_node)

# 运行
shared = {"question": "what is pocketflow?"}
flow.run(shared)

print(shared["answer"])
# 输出: You asked: WHAT IS POCKETFLOW?
```

## 第三个示例：条件分支

根据条件选择不同的执行路径：

```python
from pocketflow import Node, Flow

class DecideNode(Node):
    def prep(self, shared):
        return shared["number"]

    def exec(self, number):
        return number

    def post(self, shared, prep_res, exec_res):
        # 根据条件返回不同的 action
        if exec_res > 0:
            return "positive"
        elif exec_res < 0:
            return "negative"
        else:
            return "zero"

class PositiveNode(Node):
    def exec(self, _):
        print("这是正数！")

class NegativeNode(Node):
    def exec(self, _):
        print("这是负数！")

class ZeroNode(Node):
    def exec(self, _):
        print("这是零！")

# 创建节点
decide = DecideNode()
positive = PositiveNode()
negative = NegativeNode()
zero = ZeroNode()

# 条件分支（使用 - 操作符）
decide - "positive" >> positive
decide - "negative" >> negative
decide - "zero" >> zero

# 创建并运行流程
flow = Flow(start=decide)

flow.run({"number": 5})   # 输出: 这是正数！
flow.run({"number": -3})  # 输出: 这是负数！
flow.run({"number": 0})   # 输出: 这是零！
```

## 第四个示例：循环流程

实现一个简单的聊天机器人循环：

```python
from pocketflow import Node, Flow

class ChatNode(Node):
    def prep(self, shared):
        if "history" not in shared:
            shared["history"] = []
        return shared

    def exec(self, shared):
        # 模拟用户输入
        user_input = input("You: ")
        return user_input

    def post(self, shared, prep_res, exec_res):
        if exec_res.lower() == "quit":
            print("Goodbye!")
            return "end"  # 结束循环

        # 简单的回复逻辑
        response = f"Echo: {exec_res}"
        print(f"Bot: {response}")

        shared["history"].append({
            "user": exec_res,
            "bot": response
        })

        return "continue"  # 继续循环

# 创建自循环
chat_node = ChatNode()
chat_node - "continue" >> chat_node  # 自循环

# 运行
flow = Flow(start=chat_node)
flow.run({})
```

## 核心概念速览

### 三阶段执行模型

每个 Node 都有三个阶段：

```python
class MyNode(Node):
    def prep(self, shared):
        """1. 准备阶段 - 从 shared 读取数据"""
        pass

    def exec(self, prep_res):
        """2. 执行阶段 - 核心逻辑处理"""
        pass

    def post(self, shared, prep_res, exec_res):
        """3. 后处理阶段 - 写入 shared，返回 action"""
        pass
```

### DSL 操作符

```python
# >> : 默认转换（等同于 action="default"）
node_a >> node_b

# - : 条件转换
node_a - "action_name" >> node_b
```

### 数据流

```
       shared (全局共享)
          │
   ┌──────┴──────┐
   ▼             ▼
┌──────┐    ┌──────┐    ┌──────┐
│ prep │───▶│ exec │───▶│ post │
│ 读取  │    │ 处理  │    │ 写入  │
└──────┘    └──────┘    └──────┘
                              │
                         返回 action
```

## 常见问题

### Q: 为什么 exec 不能直接访问 shared？

这是**关注点分离**的设计：
- `prep`: 负责读取数据
- `exec`: 专注于计算逻辑（无副作用）
- `post`: 负责写入数据

这样设计使代码更易测试和理解。

### Q: action 可以是什么值？

任何字符串都可以作为 action：
- `"default"`: 默认值（使用 `>>` 时的默认 action）
- `"continue"` / `"end"`: 常用于循环控制
- `"success"` / `"failure"`: 常用于分支判断
- 自定义字符串: 如 `"search"`, `"answer"` 等

### Q: 如何处理错误？

Node 类内置了重试机制：

```python
node = MyNode(max_retries=3, wait=1)  # 最多重试3次，每次间隔1秒
```

详见 [重试与容错](./08_高级特性_重试与容错.md)。
