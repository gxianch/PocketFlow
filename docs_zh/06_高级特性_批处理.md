# 高级特性：批处理

## 概述

**批处理（Batch Processing）** 是 PocketFlow 提供的高效数据处理机制，允许一次处理多个数据项。包括两个核心类：
- `BatchNode`: 批量处理节点
- `BatchFlow`: 批量执行流程

## BatchNode

### 源码解析

```python
class BatchNode(Node):
    def _exec(self, items):
        return [super(BatchNode, self)._exec(i) for i in (items or [])]
```

`BatchNode` 继承自 `Node`，覆写了 `_exec` 方法：
- 接收一个列表作为输入
- 对每个元素依次调用 `exec` 方法
- 返回结果列表

### 执行流程

```
┌─────────────────────────────────────────────────────────────┐
│                       BatchNode                             │
│                                                             │
│  prep(shared)                                               │
│      │                                                      │
│      ▼ 返回 [item1, item2, item3, ...]                      │
│                                                             │
│  _exec([item1, item2, item3, ...])                         │
│      │                                                      │
│      ├──▶ exec(item1) ──▶ result1                          │
│      ├──▶ exec(item2) ──▶ result2                          │
│      ├──▶ exec(item3) ──▶ result3                          │
│      │    ...                                               │
│      ▼                                                      │
│  返回 [result1, result2, result3, ...]                      │
│                                                             │
│  post(shared, items, results)                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 基本用法

```python
from pocketflow import BatchNode

class TranslateNode(BatchNode):
    def prep(self, shared):
        """返回要翻译的文本列表"""
        return shared["texts"]

    def exec(self, text):
        """翻译单个文本（会被多次调用）"""
        target_lang = self.params.get("target_lang", "zh")
        return translate(text, target_lang)

    def post(self, shared, prep_res, exec_res):
        """存储所有翻译结果"""
        shared["translations"] = exec_res

# 使用
node = TranslateNode()
node.set_params({"target_lang": "zh"})

shared = {
    "texts": ["Hello", "World", "PocketFlow"]
}
node.run(shared)

print(shared["translations"])
# ["你好", "世界", "PocketFlow"]
```

### 带重试的批处理

`BatchNode` 继承自 `Node`，因此支持重试：

```python
class RobustBatchNode(BatchNode):
    def __init__(self):
        super().__init__(max_retries=3, wait=1)

    def exec(self, item):
        # 每个 item 的处理都有独立的重试机制
        return process(item)

    def exec_fallback(self, prep_res, exc):
        # 单个 item 失败时的降级处理
        return {"error": str(exc), "item": prep_res}
```

### 处理空列表

```python
class SafeBatchNode(BatchNode):
    def prep(self, shared):
        items = shared.get("items", [])
        if not items:
            # 可以返回空列表
            return []
        return items

    def post(self, shared, prep_res, exec_res):
        # exec_res 可能是空列表
        shared["results"] = exec_res if exec_res else []
```

## BatchFlow

### 源码解析

```python
class BatchFlow(Flow):
    def _run(self, shared):
        pr = self.prep(shared) or []
        for bp in pr:
            self._orch(shared, {**self.params, **bp})
        return self.post(shared, pr, None)
```

`BatchFlow` 继承自 `Flow`：
- `prep` 返回一个参数字典列表
- 每个参数字典会作为一次完整流程的参数
- 所有流程共享同一个 `shared`

### 执行流程

```
┌─────────────────────────────────────────────────────────────┐
│                       BatchFlow                             │
│                                                             │
│  prep(shared)                                               │
│      │                                                      │
│      ▼ 返回 [params1, params2, params3, ...]                │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  第1次执行流程（使用 params1）                         │   │
│  │  node_a >> node_b >> node_c                          │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  第2次执行流程（使用 params2）                         │   │
│  │  node_a >> node_b >> node_c                          │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  ...                                                        │
│                                                             │
│  post(shared, params_list, None)                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 基本用法

```python
from pocketflow import BatchFlow, Node

class ProcessNode(Node):
    def exec(self, data):
        # 从 params 获取当前批次参数
        filename = self.params.get("filename")
        return f"Processed: {filename}"

class TransformBatchFlow(BatchFlow):
    def prep(self, shared):
        """返回每次流程执行的参数"""
        return [
            {"filename": f}
            for f in shared["files"]
        ]

    def post(self, shared, prep_res, exec_res):
        shared["batch_completed"] = True

# 创建流程
process_node = ProcessNode()
batch_flow = TransformBatchFlow(start=process_node)

# 运行
shared = {"files": ["a.txt", "b.txt", "c.txt"]}
batch_flow.run(shared)
```

### 累积结果

```python
class AccumulateBatchFlow(BatchFlow):
    def prep(self, shared):
        # 初始化结果列表
        shared["results"] = []
        return [{"item": x} for x in shared["items"]]

class CollectNode(Node):
    def exec(self, data):
        item = self.params["item"]
        return process(item)

    def post(self, shared, prep_res, exec_res):
        # 每次执行都追加结果
        shared["results"].append(exec_res)
```

## 实际示例

### 示例1：批量翻译

```python
class TranslateFlow(BatchFlow):
    def prep(self, shared):
        documents = shared["documents"]
        return [
            {"doc_id": i, "text": doc}
            for i, doc in enumerate(documents)
        ]

class TranslateNode(Node):
    def prep(self, shared):
        return self.params["text"]

    def exec(self, text):
        return translate_to_chinese(text)

    def post(self, shared, prep_res, exec_res):
        doc_id = self.params["doc_id"]
        if "translations" not in shared:
            shared["translations"] = {}
        shared["translations"][doc_id] = exec_res

# 使用
translate_node = TranslateNode()
flow = TranslateFlow(start=translate_node)

shared = {
    "documents": [
        "Hello World",
        "This is PocketFlow",
        "Batch processing example"
    ]
}
flow.run(shared)

print(shared["translations"])
# {0: "你好世界", 1: "这是 PocketFlow", 2: "批处理示例"}
```

### 示例2：多文件处理工作流

```python
class FileBatchFlow(BatchFlow):
    def prep(self, shared):
        return [{"filepath": f} for f in shared["input_files"]]

class ReadNode(Node):
    def prep(self, shared):
        return self.params["filepath"]

    def exec(self, filepath):
        with open(filepath, 'r') as f:
            return f.read()

    def post(self, shared, prep_res, exec_res):
        shared["current_content"] = exec_res
        return "process"

class ProcessNode(Node):
    def prep(self, shared):
        return shared["current_content"]

    def exec(self, content):
        return content.upper()

    def post(self, shared, prep_res, exec_res):
        shared["current_result"] = exec_res
        return "write"

class WriteNode(Node):
    def prep(self, shared):
        return {
            "content": shared["current_result"],
            "filepath": self.params["filepath"]
        }

    def exec(self, data):
        output_path = data["filepath"] + ".out"
        with open(output_path, 'w') as f:
            f.write(data["content"])
        return output_path

    def post(self, shared, prep_res, exec_res):
        if "output_files" not in shared:
            shared["output_files"] = []
        shared["output_files"].append(exec_res)

# 构建流程
read_node = ReadNode()
process_node = ProcessNode()
write_node = WriteNode()

read_node - "process" >> process_node - "write" >> write_node

flow = FileBatchFlow(start=read_node)
flow.run({"input_files": ["a.txt", "b.txt", "c.txt"]})
```

### 示例3：数据管道

```python
class DataPipeline(BatchFlow):
    def prep(self, shared):
        # 将大数据集分批
        data = shared["large_dataset"]
        batch_size = 100
        return [
            {"batch_id": i, "data": data[i:i+batch_size]}
            for i in range(0, len(data), batch_size)
        ]

class ProcessBatchNode(BatchNode):
    def prep(self, shared):
        return self.params["data"]

    def exec(self, item):
        return transform(item)

    def post(self, shared, prep_res, exec_res):
        batch_id = self.params["batch_id"]
        if "processed_batches" not in shared:
            shared["processed_batches"] = {}
        shared["processed_batches"][batch_id] = exec_res
```

## BatchNode vs BatchFlow

| 特性 | BatchNode | BatchFlow |
|------|-----------|-----------|
| 执行单位 | 单个节点多次执行 | 完整流程多次执行 |
| 参数传递 | prep 返回数据列表 | prep 返回参数字典列表 |
| 复杂度 | 简单任务 | 复杂多步骤任务 |
| 灵活性 | 较低 | 较高 |

### 选择指南

**使用 BatchNode 当**：
- 只需要对每个数据项执行相同的单一操作
- 处理逻辑简单，不需要多步骤

**使用 BatchFlow 当**：
- 每个数据项需要经过完整的处理流程
- 需要根据中间结果进行条件分支
- 处理逻辑复杂，涉及多个节点

## 性能考虑

### 顺序执行的限制

标准的 `BatchNode` 和 `BatchFlow` 是**顺序执行**的：

```python
# BatchNode 内部实现
def _exec(self, items):
    return [super()._exec(i) for i in items]  # 逐个处理
```

对于 I/O 密集型任务（如 API 调用），可以使用异步并行版本。

### 异步并行批处理

详见 [异步支持](./07_高级特性_异步支持.md)：

```python
from pocketflow import AsyncParallelBatchNode

class ParallelTranslateNode(AsyncParallelBatchNode):
    async def exec_async(self, text):
        # 并行执行
        return await async_translate(text)
```

## 最佳实践

### 1. 合理的批次大小

```python
def prep(self, shared):
    items = shared["items"]
    batch_size = 50  # 避免批次过大导致内存问题

    if len(items) > batch_size:
        # 分批处理
        return items[:batch_size]
    return items
```

### 2. 错误处理

```python
class SafeBatchNode(BatchNode):
    def exec(self, item):
        try:
            return process(item)
        except Exception as e:
            return {"error": str(e), "item": item}

    def post(self, shared, prep_res, exec_res):
        # 分离成功和失败的结果
        shared["successes"] = [r for r in exec_res if "error" not in r]
        shared["failures"] = [r for r in exec_res if "error" in r]
```

### 3. 进度追踪

```python
class TrackedBatchNode(BatchNode):
    def _exec(self, items):
        results = []
        total = len(items)
        for i, item in enumerate(items):
            print(f"Processing {i+1}/{total}")
            results.append(super()._exec(item))
        return results
```
