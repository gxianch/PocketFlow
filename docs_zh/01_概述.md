# PocketFlow 概述

## 什么是 PocketFlow？

PocketFlow 是一个**仅 100 行代码**的极简 LLM（大语言模型）框架。它通过图（Graph）抽象来构建 LLM 应用，支持 Agent、Workflow、RAG 等多种设计模式。

## 核心特点

### 1. 极简轻量
- **100 行核心代码**：整个框架核心逻辑仅需 100 行 Python 代码
- **零依赖**：仅使用 Python 标准库（asyncio、warnings、copy、time）
- **零厂商锁定**：不绑定任何 LLM 供应商，可自由切换

### 2. 表达力强
支持构建各种复杂的 LLM 应用：
- **Agent 智能体**：自主决策、工具调用
- **Workflow 工作流**：多步骤任务编排
- **RAG 检索增强**：知识库检索与生成
- **多智能体系统**：多 Agent 协作

### 3. Agentic Coding
设计直观，便于 AI 辅助开发：
- 代码简洁易懂
- 模式清晰规范
- 适合 AI 代码生成

## 核心抽象

PocketFlow 将 LLM 工作流建模为 **图(Graph) + 共享存储(Shared Store)**：

```
┌─────────────────────────────────────────────────────────┐
│                   Shared Store (共享存储)                 │
│              所有节点共享的数据容器                        │
└─────────────────────────────────────────────────────────┘
                          │
         ┌────────────────┼────────────────┐
         ▼                ▼                ▼
    ┌─────────┐      ┌─────────┐      ┌─────────┐
    │  Node A │─────▶│  Node B │─────▶│  Node C │
    └─────────┘      └─────────┘      └─────────┘
         │                │                │
      Action           Action           Action
      (边标签)          (边标签)          (边标签)
```

### 核心组件

| 组件 | 功能 |
|------|------|
| **Node** | 处理单个任务的节点 |
| **Flow** | 通过 Action 连接多个节点形成工作流 |
| **Shared Store** | 节点间共享数据的通信机制 |

### 类层次结构

```
BaseNode              ─── 基础节点抽象
├── Node              ─── 带重试机制的节点
│   └── BatchNode     ─── 批处理节点
├── Flow              ─── 流程编排器
│   └── BatchFlow     ─── 批量流程
├── AsyncNode         ─── 异步节点
│   ├── AsyncBatchNode          ─── 异步批处理
│   └── AsyncParallelBatchNode  ─── 异步并行批处理
└── AsyncFlow         ─── 异步流程
    ├── AsyncBatchFlow          ─── 异步批量流程
    └── AsyncParallelBatchFlow  ─── 异步并行批量流程
```

## 设计模式

基于核心抽象，可以轻松实现以下设计模式：

### Agent（智能体）
```python
# 自主决策循环
decide_node - "use_tool" >> tool_node >> decide_node
decide_node - "answer" >> answer_node
```

### Workflow（工作流）
```python
# 顺序执行多个步骤
outline_node >> write_node >> review_node >> publish_node
```

### RAG（检索增强生成）
```python
# 检索 -> 生成
query_node >> retrieve_node >> generate_node
```

### Multi-Agent（多智能体）
```python
# 多个智能体协作
agent_a >> coordinator >> agent_b >> coordinator >> result_node
```

## 为什么选择 PocketFlow？

1. **学习成本低**：100 行代码，半小时读懂
2. **灵活可控**：无黑盒，完全掌控每个环节
3. **易于定制**：源码简单，可随意修改
4. **无厂商依赖**：可对接任何 LLM API
5. **生产就绪**：支持重试、异步、并行等企业级特性
