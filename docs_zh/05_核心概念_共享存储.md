# 核心概念：共享存储

## 概述

**Shared Store（共享存储）** 是 PocketFlow 中节点间通信的核心机制。它是一个在整个 Flow 执行期间共享的字典，所有节点都可以读写其中的数据。

## 设计理念

### 为什么使用共享存储？

传统方法中，节点间通信需要显式传递数据，容易产生复杂的依赖关系：

```
❌ 传统方式：显式数据传递
Node_A.output → Node_B.input → Node_C.input
              ↘ Node_D.input ↗
```

PocketFlow 使用共享存储，简化了数据流：

```
✅ PocketFlow 方式：共享存储
┌─────────────────────────────────────────┐
│              Shared Store               │
│  {"input": ..., "result": ..., ...}    │
└─────────────────────────────────────────┘
     ▲    ▲    ▲    ▲    ▲    ▲
     │    │    │    │    │    │
   Node_A Node_B Node_C Node_D ...
```

### 关注点分离

三阶段模型实现了清晰的数据流向：

| 阶段 | 职责 | shared 访问 |
|------|------|-------------|
| `prep` | 读取数据 | ✅ 读取 |
| `exec` | 计算逻辑 | ❌ 不访问 |
| `post` | 写入结果 | ✅ 写入 |

```python
class MyNode(Node):
    def prep(self, shared):
        # ✅ 在 prep 中读取
        return shared["input_data"]

    def exec(self, prep_res):
        # ❌ 不应访问 shared
        # ✅ 专注于计算
        return process(prep_res)

    def post(self, shared, prep_res, exec_res):
        # ✅ 在 post 中写入
        shared["output_data"] = exec_res
```

## 数据流模型

```
┌─────────────────────────────────────────────────────────────────┐
│                          SHARED STORE                           │
│                                                                 │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │  input: "用户问题"                                        │  │
│   │  context: ["历史记录1", "历史记录2"]                       │  │
│   │  answer: "LLM的回答"        ← Node_B 写入                 │  │
│   │  sources: ["来源1", "来源2"] ← Node_C 写入                │  │
│   └─────────────────────────────────────────────────────────┘  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
           │              │              │
           ▼              ▼              ▼
      ┌─────────┐    ┌─────────┐    ┌─────────┐
      │ Node_A  │    │ Node_B  │    │ Node_C  │
      │ 读 input │    │ 读 input │    │ 读 answer│
      │         │    │ 写 answer│    │ 写 sources│
      └─────────┘    └─────────┘    └─────────┘
```

## 使用模式

### 基本读写

```python
class InputNode(Node):
    def prep(self, shared):
        # 读取输入
        return shared["user_input"]

    def exec(self, user_input):
        return user_input.strip().lower()

    def post(self, shared, prep_res, exec_res):
        # 写入处理后的输入
        shared["processed_input"] = exec_res
```

### 安全读取（带默认值）

```python
class SafeReadNode(Node):
    def prep(self, shared):
        # 使用 get 避免 KeyError
        return {
            "input": shared.get("input", ""),
            "config": shared.get("config", {}),
            "history": shared.get("history", [])
        }
```

### 初始化共享存储

```python
# 方式1：运行时传入
shared = {
    "question": "什么是 PocketFlow？",
    "config": {"max_tokens": 1000},
    "history": []
}
flow.run(shared)

# 方式2：在 Flow 的 prep 中初始化
class InitFlow(Flow):
    def prep(self, shared):
        if "history" not in shared:
            shared["history"] = []
        if "config" not in shared:
            shared["config"] = {"model": "gpt-4"}
        return None
```

### 累积数据

```python
class HistoryNode(Node):
    def post(self, shared, prep_res, exec_res):
        # 初始化列表（如果不存在）
        if "results" not in shared:
            shared["results"] = []

        # 追加结果
        shared["results"].append(exec_res)

        return "continue" if len(shared["results"]) < 10 else "done"
```

### 嵌套数据结构

```python
class NestedDataNode(Node):
    def prep(self, shared):
        # 读取嵌套数据
        user = shared.get("user", {})
        return {
            "name": user.get("name", "Guest"),
            "preferences": user.get("preferences", {})
        }

    def post(self, shared, prep_res, exec_res):
        # 更新嵌套数据
        if "user" not in shared:
            shared["user"] = {}

        shared["user"]["last_query"] = prep_res
        shared["user"]["last_response"] = exec_res
```

## 典型场景

### 场景1：聊天机器人

```python
# 初始 shared
shared = {
    "messages": [],  # 对话历史
    "user_input": "" # 当前输入
}

class ChatNode(Node):
    def prep(self, shared):
        return {
            "history": shared["messages"],
            "current": shared["user_input"]
        }

    def exec(self, data):
        messages = data["history"] + [
            {"role": "user", "content": data["current"]}
        ]
        response = call_llm(messages)
        return response

    def post(self, shared, prep_res, exec_res):
        # 更新历史
        shared["messages"].append(
            {"role": "user", "content": prep_res["current"]}
        )
        shared["messages"].append(
            {"role": "assistant", "content": exec_res}
        )
        shared["last_response"] = exec_res
```

### 场景2：RAG 流程

```python
shared = {
    "query": "人工智能的应用",
    "documents": [],  # 检索到的文档
    "answer": ""      # 生成的回答
}

class RetrieveNode(Node):
    def prep(self, shared):
        return shared["query"]

    def exec(self, query):
        # 向量检索
        return vector_search(query, top_k=5)

    def post(self, shared, prep_res, exec_res):
        shared["documents"] = exec_res

class GenerateNode(Node):
    def prep(self, shared):
        return {
            "query": shared["query"],
            "docs": shared["documents"]
        }

    def exec(self, data):
        context = "\n".join(data["docs"])
        prompt = f"Context:\n{context}\n\nQuestion: {data['query']}"
        return call_llm(prompt)

    def post(self, shared, prep_res, exec_res):
        shared["answer"] = exec_res
```

### 场景3：多步骤工作流

```python
shared = {
    "topic": "人工智能",
    "outline": None,    # 大纲
    "draft": None,      # 草稿
    "final": None       # 最终稿

class OutlineNode(Node):

class WriteNode(Node):
    def prep(self, shared):

class ReviewNode(Node):

```

## 命名约定

推荐使用一致的键名命名约定：

| 类型 | 命名模式 | 示例 |
|------|----------|------|
| 输入 | `input_*` 或 `*_input` | `user_input`, `input_text` |
| 输出 | `output_*` 或 `*_output` | `llm_output`, `output_data` |
| 中间结果 | 动词+名词 | `retrieved_docs`, `parsed_data` |
| 配置 | `config_*` 或 `*_config` | `llm_config`, `config_params` |
| 状态 | `is_*` 或 `has_*` | `is_complete`, `has_error` |
| 计数 | `*_count` 或 `num_*` | `retry_count`, `num_results` |
| 历史 | `*_history` 或 `*_log` | `message_history`, `action_log` |

## 最佳实践

### 1. 明确数据所有权

```python
# ✅ 每个节点负责特定的 key
class SearchNode(Node):
    """负责写入 search_results"""
    def post(self, shared, prep_res, exec_res):
        shared["search_results"] = exec_res  # 只写自己的 key

class SummarizeNode(Node):
    """负责读取 search_results，写入 summary"""
    def prep(self, shared):
        return shared["search_results"]  # 只读需要的 key

    def post(self, shared, prep_res, exec_res):
        shared["summary"] = exec_res
```

### 2. 避免覆盖重要数据

```python
# ❌ 可能覆盖有用数据
def post(self, shared, prep_res, exec_res):
    shared["result"] = exec_res  # 每次都覆盖

# ✅ 累积或使用唯一键
def post(self, shared, prep_res, exec_res):
    if "results" not in shared:
        shared["results"] = []
    shared["results"].append(exec_res)  # 累积
```

### 3. 文档化 shared 结构

```python
"""
Shared Store 结构文档：

必需字段：
- query (str): 用户查询
- config (dict): 配置参数
  - model (str): LLM 模型名
  - max_tokens (int): 最大 token 数

可选字段：
- history (list): 对话历史
- context (str): 上下文信息

输出字段：
- answer (str): 生成的回答
- sources (list): 引用来源
"""
```

### 4. 类型提示（可选）

```python
from typing import TypedDict, List, Optional

class SharedStore(TypedDict, total=False):
    query: str
    documents: List[str]
    answer: Optional[str]
    config: dict

def prep(self, shared: SharedStore):
    return shared.get("query", "")
```

## 调试技巧

### 打印 shared 状态

```python
class DebugNode(Node):
    def prep(self, shared):
        print(f"[DEBUG] shared keys: {list(shared.keys())}")
        print(f"[DEBUG] shared content: {shared}")
        return None

    def post(self, shared, prep_res, exec_res):
        return "debug_done"

# 插入到流程中进行调试
node_a >> DebugNode() >> node_b
```

### 追踪数据变化

```python
class TrackedDict(dict):
    def __setitem__(self, key, value):
        print(f"[TRACK] Set '{key}' = {value}")
        super().__setitem__(key, value)

# 使用追踪字典
shared = TrackedDict({"input": "test"})
flow.run(shared)
```
